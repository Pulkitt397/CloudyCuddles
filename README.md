# Cloudy Cuddles 🌤️
### The perfect weather app with the cutest widgets.

Cloudy Cuddles is a high-fidelity, premium weather application built with Flutter. It combines atmospheric design with powerful functionality to give you the most cozy weather experience on Android.

![Dashboard Preview](https://raw.githubusercontent.com/Pulkitt397/CloudyCuddles/main/screenshots/dashboard.png)

## ✨ Features

- 🌍 **Global City Search**: Powered by the Teleport API for instant, real-time city suggestions worldwide.
- 📍 **Smart GPS Tracking**: Automatically detects your current location to give you immediate local weather.
- 🎨 **Glassmorphic Design**: Stunning modern UI with soft shadows, pastel gradients, and "Cloudy" aesthetics.
- 🏠 **Native Android Widgets**: Beautiful Small, Medium, and Wide widgets that live right on your home screen.
- 🌙 **Sleek Dark Mode**: A premium dark theme tailored for night-time checking.
- 📊 **Weekly Outlook**: Visualized temperature trends with a unique multi-color gradient bar.

## 🛠️ Technology Stack

- **Framework**: [Flutter](https://flutter.dev)
- **APIs**: [OpenWeatherMap](https://openweathermap.org), [Teleport City API](https://developers.teleport.org/api/)
- **State Management**: Stateful Widgets & IndexedStack
- **Navigation**: Custom Glassmorphic Bottom Dock
- **Native**: Android AppWidgetProvider (Kotlin)

## 🚀 Getting Started

1. **Clone the repo**:
   ```bash
   git clone https://github.com/Pulkitt397/CloudyCuddles.git
   ```
2. **Install dependencies**:
   ```bash
   flutter pub get
   ```
3. **Run the app**:
   ```bash
   flutter run
   ```
